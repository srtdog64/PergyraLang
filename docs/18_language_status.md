# Pergyra 언어 상태 평가

마지막 업데이트: 2026-03-13

## 요약

Pergyra는 현재 구현된 컴파일러 파이프라인과 문법 문서를 가진 프로토타입 단계의 언어다.
컨셉은 분명하지만, 실사용 언어로 보려면 모듈, FFI, 표준 라이브러리, 오류 처리, 런타임 완성도가 더 필요하다.

## 현재 강점

- 슬롯 기반 메모리 모델과 `with` 기반 해제 규칙이 문법과 런타임에 연결되어 있다.
- 제네릭, 병렬 실행, 보안 슬롯 같은 방향성이 엔진 지향 설계와 맞물려 있다.
- 렉서, 파서, 시맨틱, C 트랜스파일러, 테스트가 한 저장소 안에서 연결되어 있다.

## 현재 한계

- 문서 초안과 실제 구현 범위가 완전히 일치하지 않는 영역이 남아 있다.
- 모듈 시스템, FFI, 오류 처리, 비동기 런타임은 설계 문서 비중이 구현보다 크다.
- 표준 라이브러리와 개발 도구 체인이 아직 초기 단계다.
- Role, Party, World 계열 문법은 설계 예제가 많지만 구현과 검증은 제한적이다.

## 엔진 목표 기준 평가

- 엔진 코어 후보로는 `struct`, 제네릭, 슬롯, 병렬 실행 축이 우선 정리되어야 한다.
- 엔진 제작에 필요한 배열/슬라이스, 메모리 할당기, 핸들, 모듈, C ABI 연결이 먼저 안정화되어야 한다.
- 현재 상태에서는 엔진 언어 자체보다 엔진 언어를 위한 프런트엔드 연구 단계에 가깝다.

## 다음 기준

1. 구현 문법과 문서 문법을 하나로 유지한다.
2. 엔진 코어 문법을 기준으로 `struct`, 제네릭, 배열/슬라이스, FFI, 모듈을 우선 구현한다.
3. 예제와 테스트를 설계 문서가 아니라 현재 구현 범위에 맞춘다.
4. Role, Party, World는 코어 기능 안정화 이후 확장한다.
