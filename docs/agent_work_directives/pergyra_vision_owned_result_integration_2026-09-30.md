- Objective: an exact callable's fresh String ownership and C/LLVM projection
  must not change when unrelated routines are added or declarations reordered.
  This is the first executable slice of the compiler-world vision, not a
  keyword migration of pure calculations into subjects or zones.
- Priority: stable semantic identity and one SoT; owner-directed evidence;
  fail-closed cycles and forged facts; negative ratchet; then cost and size.
- Fact owner: existing collection ownership family. Semantic producer facts
  remain owned by `SemanticAstOwnedStringResultFactsFromResolvedFacts` and the
  registered collection owner. The direct-MIR owner validates external facts
  at admission; projection must not invent ownership from a String type/name.
- Last legitimate consumer: admitted direct-MIR GraphPlan and its C/LLVM
  materialization/cleanup projections, reached by the public compiler routes.
- Forbidden fallback: unrelated routine count as proof budget, guessed ownership
  from names/types/slots, native production retry, raised caps, or a new parallel
  ownership policy. Recursive or forged input must not acquire ownership.
- Verification and falsifier: wrapper, reordered producer, unused-tail and
  longer acyclic composition must agree; borrowed, recursive and wrong-source
  artifacts must refuse. MIR/projected-artifact transactions preserve existing
  artifacts. Public executable requests invalidate the exact old binary before
  admission, as `driver_binary_output_owner.h` and `binary_output_refusal_owner.sh`
  require; generic preservation must not override that existing owner policy.
