## Ordering conclusion

The only immediately substitutable seam in this scope is the bounded intent-observability backend name lookup. Layout, runtime-call, receiver, and target closure require their named predecessor facts before old consumers can be deleted safely. The Array<String> row must first reconcile its stale registry inventory, and compatibility evolution must first establish a production-reachable typed consumer. These classifications describe the smallest next executable evidence; they do not change registry status.
