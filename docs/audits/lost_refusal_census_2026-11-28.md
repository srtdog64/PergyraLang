# Lost refusal census, 2026-11-28

Read-only audit. No compiler code, gate or fixture changed.

The question: after `a7d7655e1` silently dropped 15 defer negatives and the
extern "C" callee identity refusal on native, are more lost refusals still
latent on main? This census compiles every fixture whose name or directory
says it must be refused, on native C and on the default (installed self-host
driver) C route, and explains every one that becomes a binary.

## Result

- **Native C: no regression.** Native C turns 284 of 1,255 refusal-named
  fixtures into a binary. 112 of them failed on an older native build
  (10-20, 10-25 or 11-14): 110 refused, 2 emitted C that did not compile.
  For 99 of the 112, native MIR on main has a compiler-selected `Clone` or
  owned String push, the copy landings the 10-19 to 10-25 and 11-12
  decisions adopted. The other 13 are self-host-only negatives that native now
  admits without a copy; all 13 run clean and none names a decision. Since
  the `226613c3c` restore (11-15), native has lost no refusal on this
  census.
- **Default C: 82 regressions by the brief's rule, none seen lost.**
  Default C admits 82 fixtures that native refuses and that no decision
  admits. No recorded sweep since 2026-11-19 shows the self-host front end
  refusing any of the 75 that the sweeps cover: default LLVM refused some of
  them, but only with `CODEGEN ERROR`, and default C admitted them in every
  C sweep. The other 7 have no earlier verdict, or were already admitted in
  the 2026-11-15 record. These are gaps in the self-host rules; no commit
  that removed a refusal was found.
- **No admitted fixture reads or frees freed memory.** Every native and
  default binary was rebuilt with `-fsanitize=address,undefined -O0` and run.
  The only non-clean runs are known: two endless recursions, one endless
  loop, two array bounds panics.
- **Incidental refusals.** Default C refuses 101 named fixtures only because
  code generation, linking or C compilation fails (`CODEGEN ERROR` 46, link
  42, C compiler 13). The self-host front end admitted each of them. Four are
  the foreach String loan negatives that read freed memory on native before
  2026-11-20.
- **Unfinished:** `driver_rung2_mutable_analysis_reject.pgy` did not finish
  within 900 s on either route.

  `-fsanitize=address,undefined`, no `-O`, `detect_leaks=0`, 10 s per run.
