# 시각 레퍼런스 (원본 만화 캡쳐)

`docs/manga_cutscene_design.md` 의 "참조 자료" 절이 이 폴더의 이미지를 임베드한다.
아래 파일명으로 캡쳐를 저장하면 설계 문서에 그대로 표시된다. (원본은 유희왕 배틀
시티 — 연출 레퍼런스로만 사용.)

- `ref_gaze.png`    — "28:" 페이지. 핑크 시선 유도(視線誘導) 화살표가 카드에서
  위로, 다시 J자로 쓸어내리는 독자 시선 경로. `ドロー` / `神の脈動!!`.
- `ref_action.png`  — 액션 스플래시. 파편 컷, 몬스터 돌출, 방사 스피드라인,
  `召雷弾!!` / `神だ!!` SFX.
- `ref_faceoff.png` — 8페이지. 카이바 vs 유우기 대치. 사다리꼴·쐐기 패널이
  페이지를 대각선으로 분할, 카드 드로우 광휘, `それが魂の交差する場所`.

저장 후 별도 작업 불필요 — 문서가 상대경로로 이 파일들을 가리킨다.
