# Call shapes for tests/self_hosted/parity/builtin_surface_parity_owner.sh.
#
# One block per row of src/common/pgy_builtin_type_table.c, plus the rows the
# gate lists in EXTRA_ROWS. A block starts with `== Name` and holds one whole
# program: the smallest well-typed program that calls the builtin. The gate
# fails when a table row has no block, so a new builtin cannot skip it.
#
# Each program prints through Log/Print only; Float results are compared
# inside the program so the printed text does not depend on float formatting.
# Every binary runs in an empty directory with `stdin-line` on stdin.
